# Практическая работа: вёрстка макетов Figma во Flutter

Выполнил: Большаков Матвей Сергеевич

Реализовано 4 макета (на оценку 5):

| № | Макет | Сложность | Файл |
|---|-------|-----------|------|
| 1 | Welcome (medinow) | простой | `lib/screens/welcome_screen.dart` |
| 2 | Mind Deep Relax | простой | `lib/screens/session_screen.dart` |
| 3 | Meditate (каталог) | сложный | `lib/screens/meditate_screen.dart` |
| 4 | Task Manager | сложный | `lib/screens/tasks_screen.dart` |

Главный экран (`lib/main.dart`) — меню для перехода к каждому макету.

## Запуск

```bash
flutter create .      # создаст папки android/ios/web, не трогая lib/
flutter pub get
flutter run
```

Картинки из Figma положи в `assets/images/` (имена указаны в `assets/images/README.md`).
